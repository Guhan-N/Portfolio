## ⚡ Technical Highlights

- **Custom 3D Infinity Cube (Dual-State Material Physics & Free Flow)**:
  - **Dark Mode**: Dark obsidian metallic with glowing neon orange wireframe lattice and orbiting data halo.
  - **White Side Inversion**: As you cross into the white section, the 3D Infinity Cube transforms into pure sculpted white porcelain with crisp coral wireframe edges and directional facet shading.
  - **Continuous Multi-Axis Free Flow**: Independent spin pivot continuously rotates and breathes on multiple axes across both dark and white sections without scroll-scrub interruption.
  - **Lenis Velocity Coupling**: Instantaneous scroll speed accelerates the 3D cube's spin rate in real-time.
  - **Floating 3D Mode Switcher**: Toggle between `3D: HYBRID`, `3D: WIREFRAME`, and `3D: SOLID` rendering modes.
- **Lenis v1.1.18 Momentum Scroll**: Smooth normalized inertia scrolling with exponential easing.
- **GSAP ScrollTrigger Synchronization**: Pinned to the global `gsap.ticker` with zero-drift lag smoothing (`lagSmoothing(0)`).
- **Scroll-Scrubbed Statement**: Text dynamically illuminates word-by-word based on scroll momentum.
- **Sticky Stacking Case Studies**: 3D depth, scale-down, and blur effects as project cards stack over each other.
- **Pinned Horizontal Reel**: Pinned horizontal track mapping vertical scroll wheel to horizontal motion for credentials & certifications.
- **Magnetic Buttons & Custom Cursor**: Spring physics on buttons and links with trailing ring interpolation.
- **Accessibility & Reduced Motion**: Full `@media (prefers-reduced-motion: reduce)` support.

## 🚀 Deployment & Local Run

### Static Site (Netlify Ready)
This project is completely vanilla HTML5, CSS3, ES6 JavaScript, and Three.js — no build step required (`publish directory: .`).

### Run Locally:
From PowerShell inside this directory:
```powershell
python -m http.server 3000
```
Then open `http://localhost:3000` in your browser.
